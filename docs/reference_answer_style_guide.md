# Reference Answer Style Guide

## Principles

- Reference answers are flexible models, not scripts to memorize.
- Every answer must include an answer skeleton.
- Keep spoken rhythm: direct answer, reason, example, extension or balance.
- Avoid dense written transitions such as moreover, therefore, notwithstanding, or in conclusion.

## Band Targets

- Band 5: 35-95 words, common vocabulary, simple reason and short example.
- Band 6: 50-120 words, topic words, natural collocations, one clear extension.
- Band 7: 70-150 words, more precise vocabulary, balanced discussion, controlled complex clauses.

## Part Differences

- Part 1: concise answer with one everyday example.
- Part 2: story structure with concrete details and reflection.
- Part 3: position, reason, example, and balance.

## Safety

- Do not imply the answer guarantees an official IELTS band.
- Do not encourage users to memorize the answer word for word.
- Personalization must use only allowed user background facts.
